按住快捷键说话 → **本地离线**识别 → 理解整句话 → 执行。全程不联网、零调用成本。

说「打开微信」就打开微信，说「设置今天下午三点的日程我要玩游戏」就真的多一条
下午三点的提醒，说「关闭微信」就**关闭**微信。

## 0.3.0 新增：从「匹配别名」到「理解句子」

0.2.0 的判定模型是一句话：**话里出现了某个别名，就执行那个动作**。
它对「打开微信」很好，对下面这些真实说法就是错的——全部是在这台机器上实测出来的：

| 你说 | 0.2.0 干了什么 | 为什么 |
|---|---|---|
| 设置今天下午三点的日程我要玩游戏 | 打开 Windows 设置 | 别名「设置」被命中（0.912），动词的宾语其实是「日程」 |
| 关闭微信 | **打开**微信 | 别名「微信」被命中（0.950），否定和动词被完全忽略 |
| 不要打开记事本 | 打开记事本 | 「不要」没有意义 |
| 打开QQ | 什么都没发生 | 配置里没有 QQ 这条 `[[action]]` |
| 打开QQ音乐（没装） | 打开浏览器 | 「打开浏览器」以 0.633 勉强命中 |

这一版把判定拆成四层，**顺序不能换**——越往前越便宜、越确定：

```
① 意图层（约 1ms，不需要模型）   动词 / 否定 / 时间 / 动态应用词典
② 别名匹配（约 1ms）             与 0.2.0 完全一致
③ 语义决策（可选，40-100ms）     Laya ONNX，分类器
④ 小模型层（可选，数百 ms）      本机大模型服务，只抽槽位
```

①②不需要任何模型，覆盖绝大多数指令；③④只在前面都没结果时才被调用——
为一句「打开微信」去等一次模型推理是荒唐的。

### 说得清楚就能听懂

- **动词和否定算数了**：「关闭微信」不会再打开微信；「不要打开记事本」
  「我不想打开计算器」不执行，并告诉你为什么
- **时间被认成参数**：「今天下午三点」被整段剥出来交给时间解析器，
  剩下的才是日程标题——不会再因为它而误判成"打开设置"
- **日程**：说「明天早上八点提醒我开会」就有一条会准时响的提醒。
  纯本地（`schedule.json`），本程序常驻所以它自己负责到点响，还能导出
  `.ics` 进手机日历。标题逐字保留你的原话，说两遍不会建两条，
  睡眠/关机之后不哑火也不翻旧账
- **打开任何装了的软件**：「打开QQ」不用先在配置里写一段。名字匹配是
  **方向敏感**的（说「QQ音乐」不会落到「QQ」上），拼音兜住 ASR 的常态听错
  （威信 → 微信），昵称表兜住毫无字面关系的叫法（扣扣 → QQ）
- **关闭应用**：有窗口的进程**不带 `/F`**——`taskkill /F` 是立刻终止，
  Word 里没保存的文档会直接没。所以先看它有没有标题窗口，有就走优雅关闭
- **小模型层（可选）**：剩下的长尾是**缺字**（「有个文件要改一下」想开记事本），
  用本机跑着的大模型服务补比训练分类器合适。三条约束让它真的是可选：
  只抽槽位不执行（模型没有"执行"这个字段可以填）、服务连不上等于功能不存在
  （静默退回前三层）、编出来的 action_id 绝不执行

### 这一版专门治的两类"静默错误"

1. **勉强命中比不执行更糟。** 说「打开QQ音乐」而没装时，0.2.0 会用
   `open.browser` 的 0.633 打开一个浏览器窗口。现在意图层解析不出对象就
   如实说「没找到叫QQ音乐的应用」，并列出最接近的候选；只有达到 0.85 以上
   的匹配（完整命中别名那种）才照旧执行。

2. **拿不准就说不确定。** 「三点」没说上午下午时按下午算，但会把
   「没说上午/下午，按下午算」写进结果——而不是悄悄猜一个。日程建错了
   比没建更烦人，它会在错的时间响。

## 升级注意

- **不需要改配置**：新增的 `[intent]` 和 `[schedule]` 都有合理默认值（都是开启的）。
  想退回 0.2.0 的行为，把 `[intent].enabled` 改成 `false` 即可。
- **`[llm]` 默认关闭**：它依赖一个本机服务（LM Studio / Ollama），
  没装是常态。开之前先跑 `voice-ctl llm --probe`。
- 日程默认落在可写数据目录的 `schedule.json`。想换位置改 `[schedule].data_file`，
  或用环境变量 `VOICE_CTL_SCHEDULE_FILE`。
- 新增两条"万能"动作 `open.target` / `sys.close_app`——它们没有固定目标，
  要开谁关谁由意图层当场解析。想固定绑某个程序，给 `open.target` 写 `target` 即可。
